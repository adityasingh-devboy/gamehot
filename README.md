# CoupleVerse – The Ultimate Couple Gaming Platform ❤️

> **Two Hearts. One Game. Endless Memories.**  
> *A premium, modern, fully responsive multiplayer gaming platform designed especially for long-distance and co-located couples.*

## ✨ Features & Highlights

- **Real-Time Multiplayer Room System**: Connect two mobile devices anywhere in the world using a unique 6-digit room code or shareable invitation link.
- **30 Fully Playable Couple Games**: Not mock cards or demos. Every game features working rules, turns, scores, animations, and sound effects.
  - **Flagship Ludo Couple Edition ❤️**: Complete 2-player board scaled perfectly for mobile phones with dice rolling, yard emergence, safe zones, token captures, home stretch, and romantic rewards!
- **Romantic & Intimate Stakes**: Every game rewards the winner with sweet couple perks (e.g. 10-minute back massages, handwritten love letters, breakfast in bed, date playlist control).
- **Floating Emoji Reactions**: Send animated floating reactions (`❤️`, `😂`, `😘`, `🔥`, `😍`, `😜`, `👏`) that float across both screens in real time.
- **In-Game Couple Chat**: Real-time room chat with custom messages and quick couple phrases ("I love you! ❤️", "Good move! 👏", "You got lucky! 😂").
- **Love Moments Celebrations**: Confetti celebrations with romantic victory quotes ("You're my favourite opponent ❤️", "Love wins, always!").
- **Couple Profile & Stats**: Track wins, losses, win rates, streaks, and customize relationship nicknames and avatars.
- **Daily Challenges & Quests**: Earn romantic badges and love sparks by completing daily gaming quests together.
- **Admin Dashboard**: Live analytics, active rooms, player counts, game availability controls, and report moderation.
- **Dark Mode & Light Mode**: Seamless theme switching with persistent memory.
- **Web Audio Sound Effects**: Zero external audio dependencies—high-fidelity procedural sound synthesizer for dice rolls, token movements, captures, and victory fanfares.

## 🚀 Getting Started

### 1. Start the Platform
To run the server with real-time WebSockets and cross-device mobile support:
```bash
npm run dev
# Or for optimized production:
npm run build
npm start
```

The server binds to `0.0.0.0:3000`:
- **Local Browser**: `http://localhost:3000`
- **Mobile Phones on the same Wi-Fi**: Open `http://<YOUR_COMPUTER_IP>:3000` on your mobile phone's browser (e.g. `http://192.168.1.15:3000`).

## 📱 How to Play on Two Mobile Phones

1. **Player 1**: Open CoupleVerse on your phone and tap **Create Room**. Select your starting game (e.g. *Ludo Couple Edition*).
2. A unique **6-digit room code** (e.g. `LOVE88`) and a shareable invitation link are generated.
3. **Player 2**: Open the invitation link on their phone, or go to **Join Room** and enter the 6-digit code.
4. Both players are paired in the **Multiplayer Lobby** showing real-time online status and avatars.
5. Tap **Ready** and start playing! Any dice roll, piece move, drawing stroke, or reaction will synchronize immediately.

## 🛠️ Technology Stack

- **Framework**: Next.js 14 (App Router) + React 18 + TypeScript
- **Styling**: Tailwind CSS + Custom Gen-Z Couple Gradients & Glassmorphism
- **Multiplayer Engine**: Node.js + Socket.IO Server with BroadcastChannel and WebRTC fallback
- **Animations & Effects**: Canvas Confetti, CSS Keyframe Animations
- **Sound Engine**: Procedural Web Audio API sound synthesizer
- **Persistence**: LocalStorage with optional Supabase PostgreSQL & Auth integration
